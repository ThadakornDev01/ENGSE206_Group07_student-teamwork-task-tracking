## 4. New / Revised Insights[cite: 6]

- **Insight 1:** ตอนแรกเราคิดว่าหัวหน้ากลุ่มแค่อยากรู้ว่างานเสร็จหรือยัง แต่จริงๆ แล้วปัญหาที่หนักกว่าคือ "การต้องมานั่งทวงงานและรวบรวมไฟล์เอง" ระบบจึงต้องเปลี่ยนสถานะให้ลูกทีมเป็นฝ่ายต้องพิสูจน์ (Push) หลักฐานเข้ามาในระบบเอง
- **Insight 2:** ฟีเจอร์ History Log ไม่ได้มีประโยชน์แค่เรื่องการสานต่องานทางเทคนิค แต่หน้าที่แฝงของมันคือการเป็น "เครื่องมือระงับข้อพิพาท (Conflict Resolution)" และเป็นหลักฐานป้องกันการเคลมผลงานผิดคน
- **Insight 3:** การออกแบบระบบนี้ ไม่ได้มีแค่การจัดเก็บข้อมูล แต่ต้องคำนึงถึงสภาพจิตใจ (Psychological factor) ด้วย เช่น การทำ Peer Evaluation จะมีประสิทธิภาพก็ต่อเมื่อนักศึกษารู้สึกว่าตนเองมี "ข้อมูลยืนยัน" คอยซัปพอร์ตการให้คะแนน ไม่ใช่เกิดจากอคติส่วนตัว
