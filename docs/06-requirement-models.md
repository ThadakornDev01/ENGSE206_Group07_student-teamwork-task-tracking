## 2. Acceptance Criteria

AC-01 — การแสดงผลรายการงานของตนเองเมื่อเข้าสู่ระบบ (Dashboard view)
Given สมาชิกกลุ่มเข้าสู่ระบบด้วย บัญชีสมาชิก

When เข้ามาที่หน้า Dashboard หลัก

Then ระบบต้องแสดงรายการงานทั้งหมดที่ตนเองรับผิดชอบ พร้อมบอกสถานะ (To Do/Doing/Done) และวันกำหนดส่งอย่างชัดเจน โดยไม่ต้องกด Filter ค้นหาเพิ่มเติม

AC-02 — ภาษาที่เป็นกลางในการแสดงประวัติการทำงาน (Neutral Wording)
Given งานมีการเปลี่ยนผู้รับผิดชอบหรือแก้ไขสถานะย้อนหลัง

When สมาชิกกดเปิดดูประวัติกิจกรรม (History Log) ของงานนั้น

Then ระบบต้องแสดงลำดับเวลา ชื่อผู้ดำเนินการ และไฟล์เดิม ด้วยภาษารายงานข้อเท็จจริงที่เป็นกลาง (Neutral wording) โดยไม่มีถ้อยคำเชิงต่อว่าหรือตัดสินความผิด

AC-03 — การสร้างและมอบหมายงานใหม่
Given หัวหน้ากลุ่มอยู่ในหน้าจัดการงาน

When กรอกชื่อระบุรายละเอียด มอบหมายสมาชิกผู้รับผิดชอบ ตั้งกำหนดส่ง แล้วกด "บันทึก"

Then งานชิ้นใหม่จะถูกสร้างและไปปรากฏบน Task Board ของกลุ่ม และหน้าแจ้งเตือน/Dashboard ของผู้รับผิดชอบทันที

AC-04 — เงื่อนไขการเปลี่ยนสถานะงานเป็น Done (Definition of Done Constraint)
Given งานอยู่ในสถานะ "To Do" หรือ "Doing"

When สมาชิกพยายามกดเปลี่ยนสถานะงานเป็น "Done" โดยยังไม่ได้แนบหลักฐาน

Then ระบบต้องปฏิเสธการเปลี่ยนสถานะ แจ้งเตือนให้แนบหลักฐาน (อย่างน้อย 1 ประเภท: ไฟล์/ลิงก์/ข้อความ) และจะยอมให้เปลี่ยนสถานะเป็น Done ได้ก็ต่อเมื่อแนบหลักฐานสมบูรณ์แล้วเท่านั้น

AC-05 — การ Reassign งานพร้อมเก็บประวัติ
Given งานที่เคยถูกมอบหมายให้สมาชิก A ทำอยู่

When หัวหน้ากลุ่มทำการเปลี่ยนตัวผู้รับผิดชอบเป็นสมาชิก B

Then ระบบต้องบันทึกประวัติการ Reassign ลงใน History Log (ระบุเวลา, สมาชิก A, สมาชิก B) โดยไม่ลบไฟล์/ข้อความเดิมที่สมาชิก A เคยอัปโหลดไว้

AC-06 — สิทธิ์การเข้าถึงข้อมูลของผู้สอน (Instructor View Limit)
Given อาจารย์ผู้สอนล็อกอินเข้าสู่ระบบ

When อาจารย์เข้าดูข้อมูลของกลุ่ม

Then อาจารย์จะเห็นเฉพาะภาพรวม Dashboard สัดส่วนงานที่เสร็จ/ค้าง และไฟล์หลักฐานของงานที่เปลี่ยนสถานะเป็น Done แล้วเท่านั้น โดยจะไม่เห็นสถานะงานที่อยู่ระหว่างทำ (Work-in-progress) และไม่สามารถแก้ไขหรือลบข้อมูลใดๆ ได้

AC-07 — การประเมิน Peer Evaluation
Given สมาชิกกลุ่มเข้าสู่หน้าแบบฟอร์ม Peer Evaluation เมื่อถึงกำหนดรอบประเมิน

When สมาชิกเลือกประเมินเพื่อนร่วมทีมแต่ละคน

Then ระบบต้องแสดงสรุปจำนวนงานและหลักฐานที่เพื่อนคนนั้นทำเสร็จเพื่อให้อ้างอิง และบันทึกผลการประเมินเพื่อนำไปคำนวณคะแนนเฉลี่ยสรุปให้หัวหน้าและอาจารย์
