## 1. User Stories

| ID | User Story | Priority | Linked FR | Acceptance Criteria |
|US-01|As a สมาชิกกลุ่ม, I want มองเห็นรายการงาน บทบาท และกำหนดส่งของตนเองในหน้าเดียว so that สามารถเริ่มทำงานได้ทันทีโดยไม่ตกหล่นและไม่ต้องคอยค้นหาในแชต|Must|FR-01|AC-01, AC-02|
|US-02|As a หัวหน้ากลุ่ม, I want สร้างงาน กำหนดรายละเอียด มอบหมายผู้รับผิดชอบ และตั้งวันส่งงานได้ so that จัดสรรภาระงานให้สมาชิกได้อย่างชัดเจน|Must|FR-02|AC-03|
|US-03|As a สมาชิกกลุ่ม, I want แนบไฟล์ ลิงก์ หรือข้อความหลักฐานก่อนเปลี่ยนสถานะงานเป็น Done so that ยืนยันว่างานเสร็จจริงอย่างโปร่งใส"|Must|FR-04|AC-04|
|US-04|As a หัวหน้ากลุ่ม, I want เปลี่ยนตัวผู้รับผิดชอบงาน (Reassign) พร้อมบันทึกประวัติย้อนหลัง so that รองรับการปรับเปลี่ยนบทบาทกลางคันโดยไม่เสียบริบทงานเดิม"|Should|FR-05|AC-05|
|US-05|"As a อาจารย์ผู้สอน, I want ดู Dashboard ภาพรวมและสัดส่วนงานของสมาชิกในกลุ่มแบบ Read-only so that ประเมินการมีส่วนร่วมของนักศึกษาได้อย่างเป็นธรรมโดยไม่กระทบพื้นที่ทำงานของเด็ก"|Must|"FR-06, FR-07, NFR-05"|AC-06|
|US-06|"As a เพื่อน Reviewer, I want ประเมิน Peer Evaluation โดยอ้างอิงจากหลักฐานการส่งงานในระบบ so that สามารถประเมินเพื่อนได้ตามความเป็นจริงด้วยข้อมูลที่เป็นกลาง"|Must|"FR-08, FR-09"|AC-07|
